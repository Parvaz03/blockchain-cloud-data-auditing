# Blockchain Enabled Privacy Preserving Cloud Data Auditing

## Project Overview

Blockchain Enabled Privacy Preserving Cloud Data Auditing is a web-based security application designed to ensure the integrity, privacy, and transparency of cloud-stored data. The system leverages blockchain technology and cryptographic techniques to provide secure cloud data auditing while protecting user privacy.

The application allows users to upload files to cloud storage, verify data integrity, and maintain tamper-proof audit records through blockchain-based mechanisms.

---

## Objectives

* Ensure secure cloud data storage.
* Preserve user privacy during auditing.
* Detect unauthorized modifications to stored files.
* Maintain immutable audit records using blockchain.
* Improve trust and transparency in cloud environments.

## Installation Guide

### Step 1: Install WAMP Server

Download and install WAMP Server on your system.

### Step 2: Copy Project Files

Place the project folder inside:

```text
C:\wamp\www\
```

### Step 3: Configure Database

1. Start Apache and MySQL in WAMP.
2. Open phpMyAdmin.
3. Create a new database.
4. Import the provided SQL file.

### Step 4: Configure Database Connection

Update database credentials in the project configuration file if necessary.

### Step 5: Run the Project

Open your browser and visit:

```text
http://localhost/cloud/
```

or

```text
http://localhost/blockchain-cloud-data-auditing/
```

depending on the folder name.

## Project Workflow

1. User uploads data to the cloud.
2. Data is securely stored.
3. Blockchain records audit-related information.
4. Auditor verifies data integrity.
5. Audit reports are generated.
6. Users can verify file authenticity and security.
